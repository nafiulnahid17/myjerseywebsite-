# BrandLogo

Original premium mark created in the 2026 studio revision (not repository source).

- `BrandLogo` props: `variant` full | mark | word (default full), `size` small |
  default | large, `tagline` boolean (default true), `label` accessible name
  (default "My Jersey"; pass "" when adjacent text names it), span attributes.
- `BrandMark` renders the crest only (`className`, optional `title`). Decorative
  by default.
- Geometry: 64-unit navy shield (`--navy2` to `--navy`), gold gradient stroke
  (`--gold-highlight`, `--gold2`, `--gold`), inner hairline, jersey collar and an
  interlocked MJ monogram. The generated favicon uses the same paths.
- Wordmark is live text: Playfair Display "My" plus gold italic "Jersey";
  Oswald tagline. Sizes scale from the root font-size (13/16/24px).
- Do not recolour, stretch or add effects outside tokens. Do not use the
  archived green raster logo for branding.
