The user requested a custom-jersey starting offer of 399TK and a team-jersey starting offer of 299TK.

**Why:** These were supplied as campaign starting prices, not a replacement price for every existing catalog jersey.

**How to apply:** Keep the two offers distinct. Do not invent minimum quantities, a discount matrix, delivery prices or guaranteed turnaround from these amounts. Final custom/team quotes depend on the customer's requirements.

The user said: “dont need to intrigate admin backend just keep the gateway -- we will setup later”.

**Why:** The management entry point is authorized now; integration is explicitly deferred.

**How to apply:** Keep the admin gateway clearly unconnected until the user authorizes setup. Never expose a public live editor or pretend a frontend password form is secure administration. Do not describe device-local profiles or prepared WhatsApp requests as authenticated accounts, submitted orders, payments or live fulfillment tracking.
