Use real team-kit reference photographs for collection cards, matched to their names; generic club/style names need explicit style-reference labels rather than invented official associations.

**Why:** The user selected official team reference images instead of AI concepts and said, “analyze name of jersey and include image.”

**How to apply:** When replacing collection imagery, distinguish team references from verified photos of My Jersey inventory. Do not infer official merchandise status or team affiliation from an image.

A CDN response at a requested large size is not evidence of a native high-resolution original.

**Why:** Public jersey-image providers offer resized renditions; published source files can be substantially smaller than the requested rendition.

**How to apply:** Verify actual published dimensions, preserve source attribution, and disclose source limitations instead of silently upscaling and calling the output an original 4K photo.
